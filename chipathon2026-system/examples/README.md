# Examples

`info.yaml` follows the participant-facing format from the live specification.
`lvs_config.json` demonstrates variable expansion of `$TOP_SOURCE` and `$UPRJ_ROOT`.

A production padring template is intentionally **not** synthesized here. The live
specification says the physical `.cfg` is the geometry source of truth and still
lists N/S numbering direction and some power assignments as unfinished. Use the
production template once those decisions are committed to the repository.
